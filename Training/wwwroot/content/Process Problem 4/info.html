Customer states that the machine runs normally the first cycle but then doesn't inlet any more boards until they trigger the inlet pip, then it runs normally for the rest of the Batch.

Hint 1

There are two problems with this Process, fixing either one will correct the issue.

Hint 2

All Lane Entry Conditions are correct.

Hint 3

There is one missing script.

Hint 4

One of the Lane's Run Settings is incorrectly configured.

Answer

Problem 1: Missing Script

The `Move In To Inlet` Lane is missing the `SMEMA Conveyor Ready` script.

Find the 'Previous Machine' source in the toolbox and add the script to the lane.

Configure the script to turn on the Upstream Ready signal.


Problem 2: Misconfigured Lane Run Setting

The `SMEMA Ready Lane` Lane has its Run Setting configured incorrectly.

The Run Setting is set to `Run Always Skip First Cycle`, but should be `Run Always Skip Last Cycle`
