Customer states that while this machine is running Production, after the first board comes in, the upstream machine does not wait at the outlet before attempting to move in a board.

Hint 1

All Lane Entry Conditions are correct.

Hint 2

One script is missing.

Hint 3

The missing script is sourced from 'Previous Machine'

Answer

Move to Process Lane

This lane is missing the SMEMA Not Ready script.

Find the 'Previous Machine' source in the toolbox and add the script to the lane.

Configure the script to turn off the Upstream Ready signal.
