Customer states the machine never inlets any boards after starting Production.

Hint 1

All Lane Entry Conditions are correct.

Hint 2

No scripts are missing or misconfigured.

Hint 3

No Lanes have been reordered.

Hint 4

All Lane Run Settings are correct.

Answer

The Workflow Creation Condition is missing

Open the Workflow Configuration menu and edit the Creation Condition

The Condition should be: `Upstream Board Available or PIP7000`
